## Brand & Style

This design system channels a high-performance, distraction-free cyberpunk aesthetic blended with clinical, hyper-focused minimalism. Designed for competitive typists, software engineers, and productivity enthusiasts seeking flow state, the interface delivers the ambiance of a specialized diagnostic terminal without visual noise.

The style fuses low-light ergonomic dark modes with electric telemetry accents. Monospaced HUD metrics, razor-thin translucent surfaces, and subtle ambient luminescences direct focus onto immediate keystroke execution while giving post-run diagnostics an analytical, pro-grade console feel. Keystroke telemetry, real-time WPM feeds, and AI coaching outputs reflect a balance between high-contrast legibility and subdued peripheral visual noise.

## Colors

The palette operates in a native dark environment. The canvas layers two deep obsidian tones (`#0F111A` baseline canvas and `#161926` panel surface) to maintain visual depth while preventing eye fatigue during intense typing runs.

- **Primary Accent (`#00F0FF`):** Electric Cyan drives system focus, primary calls-to-action, caret tracking, and high-velocity milestones.
- **Secondary Accent (`#10B981`):** Vivid Emerald Green serves strictly as positive validation, tracking correct keystrokes, accuracy highs, and performance gains.
- **Tertiary Accent (`#EF4444`):** Soft Crimson highlights error strikes, pacing drop-offs, and critical system alerts without jarring optical glare.
- **Neutral Core:** High-contrast crisp white (`#F8FAFC`) renders the active target glyph and key data figures, while muted slate (`#94A3B8`) suppresses inactive, upcoming text, gridlines, and baseline metrics.

## Typography

The type system creates an intentional dual-engine reading structure:

1. **JetBrains Mono** powers the typing arena, character targets, live counters, keyboard heatmaps, and telemetry data tables. It guarantees strict character alignment, uniform cursor travel, and terminal-grade clarity.
2. **Inter** powers UI navigation, descriptive prose, analytics breakdowns, and AI feedback panels. It balances the angular nature of the code font with effortless legibility.

The `body-lg` mono token is calibrated specifically for the typing arena: loose vertical leading and discrete character spacing prevent visual collision during 150+ WPM typing runs.

## Layout & Spacing

The layout adopts a fixed-width, centered stage model for the primary typing arena (capped at 960px to preserve comfortable optical tracking limits), shifting to a fluid 12-column grid for analytics dashboards, heatmaps, and AI coaching breakdowns.

- **Breakpoints:** Mobile (up to 640px), Tablet (641px–1024px), Desktop (1025px+).
- **Mobile Reflow:** In the mobile viewport, secondary telemetry collapses into compact pill badges above the text line; full keyboard views hide in favor of streamlined finger-accuracy heat indicators.
- **Rhythm:** Spacing follows a 4px base increment. High-density component clusters (HUD gauges, stats) use `space-xs` and `space-sm`, while sectional divisions and the typing canvas use `space-xl` to maintain an uncluttered focus corridor.

## Elevation & Depth

Visual hierarchy avoids heavy drop shadows, relying instead on tonal surface layering, glassmorphic refraction, and edge luminosity:

- **Baseline Canvas:** Flat obsidian `#0F111A`.
- **Level 1 (Card/Container Surfaces):** Translucent `#161926` at 85% opacity with an 8px backdrop blur and a 1px ghost border (`rgba(255, 255, 255, 0.06)`).
- **Level 2 (Popovers, Active Modals, Overlays):** Elevated obsidian `#1A1E2E` at 95% opacity with 16px backdrop blur, surrounded by an active luminescence border (`rgba(0, 240, 255, 0.35)`).
- **Active State Glow:** Focused cards, active interactive elements, and streak milestones project an ambient aura (`box-shadow: 0 0 20px rgba(0, 240, 255, 0.15)`), eliminating harsh artificial depth in favor of a subtle backlit terminal glow.

## Shapes

This design system leverages a tight, technical shape language (`roundedness: 1`, base 0.25rem / 4px). This preserves the sharp, engineered aesthetic of developer tooling while softening key interaction targets just enough to remain modern.

- Base containers, data cards, keycaps, and input controls utilize 4px (`rounded-sm`).
- Modal sheets, performance report viewports, and outer dashboard panels scale to 8px (`rounded-lg`).
- Navigation mode toggles, status tags, and mini-chips use full rounded pill geometry (`9999px`) to create clear visual contrast against angular data cards.

## Components

### Buttons
- **Primary:** Filled electric cyan (`#00F0FF`) with dark obsidian text (`#0F111A`), `label-md` uppercase typography, and a subtle edge aura on hover (`0 0 14px rgba(0, 240, 255, 0.4)`).
- **Ghost/Tertiary:** Transparent background, 1px slate outline (`rgba(148, 163, 184, 0.2)`), muted slate text shifting to crisp white upon hover.
- **Micro-Actions:** Monospaced icon/shortcut button with keycap appearance (`Ctrl+Enter`, `Tab+Enter`) framed in low-opacity slate containers.

### Typing Arena (Core Component)
- **Upcoming Text:** `body-lg` JetBrains Mono in muted slate (`#94A3B8`) at 60% opacity.
- **Active Target:** Crisp white (`#F8FAFC`) with a blinking smooth electric cyan (`#00F0FF`) vertical caret or glowing underline block.
- **Correct Stroke:** Emerald green (`#10B981`) with instant zero-latency fill.
- **Error Stroke:** Soft crimson (`#EF4444`) with an optional soft red background tint on space or trailing characters.

### Mode Chips & Badges
- **Status/Filter Chips:** Pill-shaped, semi-translucent dark slate background with 1px border. Selected state swaps to electric cyan border with glowing text.
- **Terminal Badges:** Sharp 4px rounded rectangles with uppercase monospace labels (`label-sm`), featuring high-contrast colored micro-dots indicating AI status or live socket connections.

### Inputs & Selection Controls
- **Input Fields:** Recessed surface tint (`rgba(15, 17, 26, 0.8)`), 1px slate border transitioning to electric cyan upon focus, accompanied by a soft neon inner glow.
- **Checkboxes & Radios:** Sharp square and circular micro-switches; checked state displays a solid cyan or emerald core with zero elevation blur.

### Cards & Dashboards
- **Diagnostic Metric Cards:** Translucent panels housing micro WPM, burst speed, raw error counts, and consistency percentages. Metric numbers render in `JetBrains Mono` headline sizes, accompanied by sub-labels in `Inter` muted slate.
- **AI Coaching Feed:** Surface accented with a left-rail 2px vertical neon cyan stripe, providing real-time, context-aware suggestions (e.g., finger placement anomalies, rhythm variance) rendered in clean `Inter` body text.
